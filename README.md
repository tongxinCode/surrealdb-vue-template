# surrealdb-vue-template

Keep pure, keep latest.

Vue 3 + TypeScript + Vite + Surrealdb + Websocket

### Init Database

Use src/surrealdb/* to init database

## Init Frontend

### Change url in .env

```
VITE_SURREALDB="ws://SURREALDBURL/rpc"
```

### Install dependencies

```
pnpm install
```

### Run

```
pnpm dev
```
